# Permis LB

Practice exams for the Lebanese driving theory test, built from the official
question-bank PDF: **340 questions in Arabic, French and English**, including
101 road-sign questions with the sign images.

Pick your language, licence category and number of questions, sit the exam,
then read the full correction.

## Running it

`index.html` is completely self-contained — no build step, no server, no
network calls. Open the file directly, or serve the folder over HTTP.

## Deploying

Any static host works. The site is already configured for GitHub Pages
(`.nojekyll`), and ships a web app manifest plus a service worker, so it can be
installed to a phone home screen and used offline.

## A note on the answers

Answers are reproduced exactly as printed in the official PDF, including a
handful of places where the source's own wording is loose or arguably wrong.
They are kept verbatim because those are the answers the real exam marks as
correct.
